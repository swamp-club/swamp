# App troubleshooting

| Symptom                                                      | Cause and fix                                                                                                                                                                                                                                                                        |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| App missing from `/apps`                                     | Not approved (`swamp app list`), the viewer lacks `read` on `access:swamp/apps/<name>`, or it was never built (`dist/` absent).                                                                                                                                                      |
| Approved app went back to "needs review"                     | Its capabilities, `run:`, `methods:` or a method list changed, or it moved between repo, source and pulled extension. Approve again.                                                                                                                                                 |
| `app_capability_denied`                                      | The request, workflow or behavior is not in `app.yaml`. Add it, rebuild, and have it approved again.                                                                                                                                                                                 |
| `app.yaml: methods.0.methods: each entry lists the methods…` | Each `methods:` entry needs `methods: [name, …]`; older apps used `- model: x` alone.                                                                                                                                                                                                |
| `not_available_locally`                                      | The local dashboard refuses runs, method runs and some streams. Use `swamp serve --dashboard`, or `createMockHost`.                                                                                                                                                                  |
| "needs app platform 1.N, which this swamp does not have"     | `platform:` asks for a newer minor than the running swamp; upgrade swamp or lower `platform:` if the app does not use the newer API.                                                                                                                                                 |
| Module error "does not provide an export named X" at load    | The app uses an export newer than the swamp serving it, and `platform:` does not say so. Set `platform: "1.N"`.                                                                                                                                                                      |
| Blank frame, `Failed to load module script`                  | `base: "./"` was overridden, or a request for `/app-platform/…` 404s because serve runs without the dashboard.                                                                                                                                                                       |
| `bunx tsc` cannot find `@swamp-club/*`                       | `.swamp-platform/` is missing; run `swamp app build` or `swamp app dev` once to write it.                                                                                                                                                                                            |
| Hooks crash: "Invalid hook call" / two Reacts                | A dependency pulled its own React. Keep `react` and `react-dom` as dev dependencies at the platform's versions only.                                                                                                                                                                 |
| `toast()` shows nothing                                      | Import `toast` from `@swamp-club/ui` (platform `"1.3"`), never from `sonner`, which bundles a second store; keep `<Toaster />` in `main.tsx`.                                                                                                                                        |
| Styles unstyled or Tailwind classes missing                  | `src/index.css` must keep `@import "tailwindcss"` and `@import "@swamp-club/app-sdk/theme.css"`.                                                                                                                                                                                     |
| A kit `Select` throws on an "any" option                     | The kit's `Select` is radix, which refuses `value=""`; use a placeholder value such as `"__any"` for "all" and "none".                                                                                                                                                               |
| `extension quality` warns about licences or stale packages   | It audits every package in the app's `bun.lock`, dev tools included; warnings do not block a push.                                                                                                                                                                                   |
| `fetch` to an API fails with a CORS error                    | The frame's origin is `null`. Move the call into a behavior and read its data.                                                                                                                                                                                                       |
| Push refuses the app                                         | The message names the cause: every locked package must come from the npm registry with an integrity hash; no `overrides`, `resolutions`, `trustedDependencies`, `patchedDependencies` or `workspaces`; a name in the extension's collective. Fix `package.json`, then `bun install`. |
| `swamp app dev` shows nothing in the dashboard               | Open `swamp dashboard` in the same repo; the app must be under this repo's `extensions/apps/` and approved.                                                                                                                                                                          |
